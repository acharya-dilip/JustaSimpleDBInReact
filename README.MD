# This is a simple Dashboard But In REACT!!!!
Made by Dilip Acharya while learning PHP and laravel and React
and this dashboard has many features ranging from meeting announcement
to a dashboard where you can view all of the progress made by the club
in the form of Posts and also you can view the members of the club and their details in the members section
and an admin pannel for the leaders but now in REACTTT!!!!.

# Features but now using REACTTTT
- Dashboard Posting for Leaders
- Dashboard Post viewing for members
- Meeting Announcement for Leaders
- Meeting Announcement viewing for members
- Members details everyone
- Admin Pannel for leaders to modify the details of the members

  # Extra Stuff but in REACTTTT!!!
- For registration of new members there's a a form at /registration
- After they register you have to assign them  a role from the admin pannel only then will they be visible in the members section
- Dashboard posting perms and the meeting posting perms along with the admin pannel perms are only available if you've got role 'Leader' in the users table in the database
- Note this project is meant for you to clone and modify according to your club and is a template for you to edit and  build on

# Run Locally
- Clone the project
- Rename the example.env file to .env
- Start your apache and mysql server and create a database named "justaSimpleDatabase"

Then Simply run it like you would run every laravel program.
